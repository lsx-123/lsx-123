## 🛠️ 研究与工程方向

- **系统工程与MBSE**：设备统一元模型、SysML v2、多视图架构、需求与验证追溯。
- **精密装备与LDW**：运动、视觉对准、DMD曝光、标定、补偿与套刻精度。
- **控制软件**：C#/.NET、WPF、Clean Architecture、DDD、Workflow、HAL与自动化测试。
- **虚拟设备与仿真**：设备行为模拟、SIL/HIL、物理模型与虚拟调试。
- **数据智能**：设备数据治理、可观测性、故障诊断、AI Agent与数字孪生。
